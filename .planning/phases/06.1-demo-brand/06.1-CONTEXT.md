### 2. 아이콘 5종 중 알파 채널을 가진 것은 하나뿐이다

| 파일 | 크기 | 형식 | 알파 | 실제 모습 |
|---|---|---|---|---|
| 아이콘1 | 238×104 | PNG **RGBA** | ✅ | 노랑 스티커 박스 + 보라 워드마크 |
| 아이콘2 | 512×206 | PNG palette (tRNS 없음) | ❌ | 보라 워드마크 / **흰 배경** |

| 아이콘4 | 493×493 | PNG palette (tRNS 없음) | ❌ | 검정 원 + 흰 물결 / **흰 배경** |
| 아이콘5 | 447×447 | JPEG | ❌ | **`#FFF500` 정사각** + 진회색 원 + 노랑 물결 |

**"다크 배경에 투명 워드마크"는 이 자산으로 불가능하다.** 그러니 배경을 없애려 싸우지 않고
**형태로 쓴다** — 아이콘5의 노랑 정사각은 `border-radius` 만 주면 그 자체로 앱 아이콘 타일이고,
다크 UI 위에서 가장 자연스럽다. 아이콘4는 흰 배경 탓에 어두운 면에서는 못 쓰지만, 원형으로 잘라
**밝은 면**(S6 페르소나 카드의 `--card-grad`)에 놓으면 정확히 맞는다.

### 3. 데모의 노랑은 이미 밀리의 노랑에서 왔다

실측 — 아이콘5 배경 `#FFF500`, 아이콘1 박스 `#F1DA56`.
현재 토큰 `--accent: #F5E06E`. 밀리의 원색을 다크 UI 가독성에 맞춰 낮춘 값이다.

디렉터리를 통째로 복사하므로 `demo/assets/brand/` 는 자동으로 이미지에 들어간다.

## 설계 결정

### D-01 아이콘 2종을, 각자의 배경이 자산이 되는 면에 쓴다
- **아이콘5 → 앱 아이콘 타일.** `#FFF500` 정사각에 `border-radius: 22%`. 다크 UI 위에서
  홈 화면의 앱 아이콘처럼 읽힌다. 마크의 주력.
- **아이콘4 → 모노 원형 마크.** `border-radius: 50%` 로 검정 원만 남기고, **밝은 면에서만** 쓴다.
- 아이콘1·2·3 은 쓰지 않는다. 1 은 보라 워드마크라 노랑 계열과 부딪히고, 2·3 은 흰 배경이
  다크 UI 어디에도 안 붙는다.

### D-02 이모지 제거 범위 = 픽토그래프 7개만
`s6_persona.js` 5개 · `s0_start.js` 2개. 타이포그래피 기호(★ ✓ ● ○ ← → ↔)는 **남긴다**(위 실측 1).

### D-03 S0 시작 화면 — 이모지 자리에 앱 타일
`🧝👩‍🦱` → 아이콘5 타일 88px 1개. 제목 아래 중앙. 화면이 "이모지 두 개"에서
"제품 스플래시"로 바뀐다. 파일 1행 주석("이모지로 대체한다")도 함께 갱신한다.

### D-04 S6 페르소나 아트 — 브랜드 마크가 아니라 모노그램
페르소나 4종(오디세우스·셜록 홈즈·돈키호테·제인 에어)은 **문학 캐릭터**라, 여기에 회사 마크를
넣으면 의미가 틀어진다. 이름 첫 글자(오·셜·돈·제)를 원형 플레이트에 크게 앉힌 **모노그램**으로
바꾼다. 카드가 `--card-grad`(밝은 노랑 그러데이션)라 어두운 글자가 잘 붙고, 장서표(ex-libris)처럼
읽힌다. 자산 0개, CSS 만.

> 더 공들인 대안 — 페르소나별 인라인 SVG 4종(신전·돋보기·말·촛대를 선으로). 시간이 남으면
> 그때 올린다. 모노그램이 먼저 서 있어야 대안을 비교할 수 있다.
