# Notion 조판 가이드 — report/draft.md → PDF 5장

## 0. 준비
- 원고: `millie-rec/report/draft.md` 최종본(커밋 예정). 그림: `millie-rec/report/figures/`(repo 밖) — `p5_01_onboarding.png` ~ `p5_06_home_after.png` · `p5_qr.png` · `eval_bar.png`.
- Notion 새 페이지(비공개) 제목 = "밀리의서재 메인 영역 추천 시스템 설계". 원고 첫 줄 `# 밀리의서재 …` H1은 페이지 제목으로 쓰고 본문에는 붙이지 않는다.
- 원하면 Advisor가 Notion MCP로 페이지를 생성할 수 있다(선택 — 한 줄로 요청).

## 1. 붙여넣기 순서 (장 = H1 `# 1.`~`# 5.`)
1. draft.md를 전체 선택 → Notion 빈 페이지에 붙여넣기(마크다운 자동 변환). 표는 Notion 표로, `---`는 구분선으로 들어간다.
2. 장 경계: 각 `# N.` heading 앞에 구분선이 있는지 확인. Notion PDF 내보내기는 페이지 나누기를 자동으로 하지 않으므로 장 수는 내보내기 결과로 확인한다.

## 2. mermaid 4개 — 코드 블록 언어를 Mermaid로
- 붙여넣기 후 ```` ```mermaid ```` 블록은 코드 블록이 된다. 각 블록 왼쪽 위 언어 선택 → **Mermaid**. 오른쪽 위 "Preview"(또는 Split)로 전환하면 렌더된다. 4곳: 1장 §1-4(그림 1) · 2장 §2-1(그림 2) · 3장 §3-1(그림 3) · 4장 §4-1(그림 4).
- 렌더가 너무 크면 블록 폭은 그대로 두고 문장을 지운다(폰트·여백 축소 금지).

## 3. `> ★` blockquote 3개 → callout 전환 (5장 §5-2)
- Notion은 `> ` 인용을 인용 블록으로 받는다. 각 인용 블록에서 `/callout`으로 전환(블록 메뉴 → Turn into → Callout) 또는 내용을 잘라 새 callout에 붙인다. 아이콘 ★, 배경은 앵커=노랑 · 난이도=파랑 · 시간 가변 가중치=초록(Claude's Discretion, 바꿔도 됨).
- 3곳: `★ 앵커` · `★ 난이도` · `★ 시간 가변 가중치`. 전환 뒤 원고의 `> ` 기호가 남지 않았는지 확인.

## 4. 그림 삽입 (자리 표시 줄을 지우고 이미지를 넣는다)
- **4장 그림 5 비교 막대**: `(그림 5 · 비교 막대 — report/figures/eval_bar.png, …)` 줄을 지우고 그 자리에 `eval_bar.png` 업로드 → 폭 1/2(가운데 정렬). 캡션은 원고의 `그림 5. …` 줄을 이미지 캡션으로 옮긴다.
- **5장 QR**: 표 `| 데모 | QR |`의 오른쪽 셀 `(QR — report/figures/p5_qr.png, …)`를 지우고 `p5_qr.png` 업로드(폭 1/6). 표 안 이미지가 어색하면 표를 2컬럼 블록으로 바꾸고 오른쪽 컬럼에 이미지.
- **5장 그림 6 캡처 3×2**: `(그림 6 · 데모 캡처 3×2 — …)` 줄과 캡션 표(①~⑥)를 지우고, 3컬럼 블록 2개(위 ①②③ · 아래 ④⑤⑥)에 `p5_01`~`p5_06` 순서대로 업로드. 각 이미지 캡션 = 원고 표 셀 문구(`① 취향 설정 — 5권 선택` …). 파일명 괄호는 캡션에 넣지 않는다. 각 폭 1/3, 6장 전체가 약 1/3페이지.
- 이미지에 밀리 표지가 들어 있으므로 Notion 페이지는 **비공개 유지**, PDF만 제출한다.

## 5. PDF 내보내기
- 오른쪽 위 ··· → Export → Format **PDF** · Include content **Everything** · Page format **A4** · Scale **100%**. 폰트·여백은 바꾸지 않는다.
- 내보낸 PDF 장 수를 확인한다(macOS 미리보기 하단 또는 `pdfinfo <file> | grep Pages`).

## 6. 장 수 회신 (Advisor에게 한 줄)
- "N장" 한 줄로 회신한다. 5장 초과면 Advisor가 넘친 장의 문장을 차순대로 지운 뒤(1~4장: 해석 문단 → 각주 부연 → 표 행 축약 / 5장: 캡션 축약 → 4층 표 흡수 → 시나리오 2문장 → 앵커 4번째 문장 → 로드맵; 필수 문장 7·★3·5권 표·URL·클릭 경로·숫자 출처·mermaid 4는 보존) 다시 붙여넣기를 요청한다. 5장 이내면 그 PDF가 제출본이다.
